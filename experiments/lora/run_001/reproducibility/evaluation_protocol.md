# Evaluation protocol, fixed before final test generation

Primary unit: normalized slang term, absent from training. All 181 frozen test rows (154 terms) are scored; duplicate rows within a term are averaged before paired statistics. Reference labels are original dataset descriptions, which can be ambiguous, outdated, or mismatched to usage. They are weak supervision, not verified contextual truth. Public-data pretraining contamination is unknown.

Primary measured proxy: ROUGE-L token F1, implemented with word-token longest common subsequence. Also report reference content-word coverage (a bag-of-words proxy, not curated key-concept coverage), response length, empty outputs, repeated trigrams, and assistant-only teacher-forced cross entropy/perplexity. Neither overlap nor perplexity establishes semantic accuracy. No embedding model is downloaded and no paid/local self-judge is treated as ground truth.

Generate with greedy decoding, 64 new tokens, the fixed checkpoint chat template, and template 0. Zero-shot and LoRA use the same inputs. Few-shot uses the first two eligible distinct training terms, fixed by file order. Examples include their own training answers, never the queried answer. Generation receives only term and usage; targets are joined after prediction. Dataset Context metadata is excluded in every condition because it often reveals meaning. A term-only inference ablation measures the value of the usage sentence with unchanged weights and decoding. Extra-context experiments require independently sourced non-definitional context and are not fabricated from metadata.

Configuration selection uses validation only. Run the untouched base on 16 validation rows zero-shot/few-shot first. Smoke on 16 training examples for two optimizer steps. Use measured resources to choose one practical main LoRA budget; training stops on validation loss patience or the time cap. Choose the lowest validation-loss adapter, freeze it, then generate all final test conditions. No prompt, cutoff, or hyperparameter changes based on final test scores. Re-running saved generation is allowed only with identical fingerprints; altered configurations get new run IDs and must be labeled exploratory.

Report term-macro paired mean differences and 95% paired bootstrap intervals with seed 42 and 10,000 resamples. Each draw samples terms with replacement and preserves pairs. This estimates held-out term sampling uncertainty conditional on these trained weights, not training-seed uncertainty. Permutation p-values are exploratory, unadjusted for multiple comparisons; no confirmatory significance claim. Strong dependence, biased weak labels, and small OOD sets limit inference. Data/rank curves require actual trained configurations; never draw invented points.

OOD: authored software-community examples linked to official definitions, filtered against every dataset split by normalized term. They are diagnostic, not an external benchmark or a human-validated gold set. A 25-prompt general capability suite covers reasoning, factual QA, summarization, instructions, and coding. Strict exact match is reported only for objective short-answer categories; summarization needs human review. Do not execute generated code.

Human review fields remain blank until reviewed. Rubric: 2 = correct sense and context, concise and no material false claim; 1 = partially correct but missing necessary meaning or overly broad; 0 = wrong sense, contradiction, or invented meaning; null = uncertain/unscorable reference. Reviewers should be blind to condition and evaluate the usage sentence, not reward overlap alone. Error labels: wrong_sense, context_ignored, hallucinated_definition, overly_generic, excessive_slang_style, possible_memorization. Improvements/regressions/both_fail require paired independent human correctness labels; lexical deltas are only candidates for review. Possible memorization cannot be inferred solely from a good answer.

## Predeclared small training ablations

Before viewing final test outcomes, add three one-epoch training runs: rank 8/full data (control), rank 4/full data, and rank 8/a nested 25% term sample. These fixed-budget supplemental runs share seed 42, alpha 16, dropout .05, optimizer and decoding. The rank pair has identical epoch/update count and scheduler. Alpha/r changes as part of the rank setting. The data comparison holds epochs constant; update count and its warmup/decay schedule therefore change with data size. It measures data plus resulting exposure budget, not data volume at fixed steps. Compare only these one-epoch runs in data/rank curves; the three-epoch selected main model is a separate result. These are predeclared test comparisons, not test-selected configurations.

A second one-epoch rank-8/full-data run uses training seed 123, keeping the original split seed 42 and all other settings fixed. Report the mean and sample standard deviation across seeds 42 and 123 as a limited repeatability check; two seeds are not a robust estimate of training variation, and the main three-epoch result still has one seed.
